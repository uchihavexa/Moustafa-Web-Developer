# Moustafa - Web Developer Portfolio

Personal developer portfolio website built with React 19, TypeScript, Vite, and Tailwind CSS v4.

## Features

- **Modern & Classy Design**: Responsive layout with dark and light theme support, frosted glass header, and bespoke typography.
- **Micro-Interactions**: Ambient background glow, live status beacons, smooth morphing mobile hamburger menu, staggered scroll reveals, and card lift effects.
- **Featured Projects**: Showcase of real-world projects with live demos and repository links.
- **Fast & Accessible**: Built with accessible semantic HTML, high performance, and zero external runtime UI dependencies.

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Bundler & Tooling**: Vite 8, Oxlint

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation & Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Check TypeScript and build bundle
npm run build

# Preview production build locally
npm run preview
```
